Projet E5 — Système de Gestion de Parc Informatique

Projet BTS SIO - 2025

Développement d'une application web complète pour la gestion d'un parc informatique d'entreprise. Le système permet de suivre l'inventaire du matériel, gérer les interventions techniques et planifier la maintenance préventive.

Fonctionnalités développées

  • Planification de la maintenance préventive

  • Export de rapports PDF

Compétences mobilisées

  • Conception de base de données relationnelle
  • Développement backend avec PHP
  • Interface utilisateur responsive
  • Sécurisation des accès et des données
  • Tests unitaires et d'intégration

Projet E5 — Infrastructure Réseau Sécurisée

Projet BTS SIO - 2025

Description du projet

Conception et déploiement d'une infrastructure réseau sécurisée pour une PME. Le projet inclut la mise en place de VLANs, d'un pare-feu, d'un VPN et d'un système de supervision réseau.

Technologies utilisées

pfSense Cisco Packet Tracer VLANs OpenVPN

Réalisations techniques

  • Segmentation réseau avec VLANs (Administration, Production, Invités)
  • Configuration d'un pare-feu pfSense avec règles de filtrage
  • Mise en place d'un VPN pour l'accès distant sécurisé
  • Déploiement d'un serveur DHCP et DNS
  • Système de supervision avec Nagios
  • Documentation complète de l'infrastructure

Compétences mobilisées

  • Architecture réseau et protocoles TCP/IP
  • Sécurisation des infrastructures
  • Configuration de pare-feu et VPN
  • Supervision et monitoring réseau
  • Documentation technique professionnelle
